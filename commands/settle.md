The end-of-context ritual — deposit everything this session knows into the graph before compaction, so nothing lives only in a context about to vanish.

Call the osiris MCP tool `settle` with NO arguments first (read-only): a one-call completeness verdict — open obligations fleet-wide, whether a handoff marker exists, and, with `repo_path=<your repo>`, any uncommitted git work.

Then ACCEPT your brain-dump, same or a follow-up call: pass `decisions`, `threads_open`, `threads_resolve` (each a dict of that verb's own kwargs) — every ruling not yet recorded, every loose end as an obligation (kind='obligation'), every thread you actually closed. Put `is_handoff: true` on your STATE-OF-THE-BOARD decision so your successor finds it directly.

settle then CONFIRMS against the updated graph, returning `complete: true` only when nothing is left unwritten; if not, it names what's missing — write that, then you're safe to compact. Mount first if not mounted.
