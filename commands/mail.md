Check this project's mailbox. Call the osiris MCP tool `inbox` with peek=true first (mount with cwd + $CLAUDE_JOB_DIR if not mounted). Render each message compactly: id, sender, age, thread, body. A peek leases nothing, but you can SETTLE straight from it — no second read needed: reply with send(reply_to=<id>) or ack with inbox(ack=[the ids you just rendered]); both settle directly. Only messages needing deeper handling warrant a non-peek read (leases an hour).

WHOSE TAB THIS IS DECIDES WHO SAYS GO: in the OPERATOR's own tab, act on a message only at the operator's word. In a WORKER's tab (you hold a seat with a manager), a grade='ask' DM from your manager/coordinator IS the go — lease it with a non-peek read and START the work this same turn; never ask the operator to confirm what the manager already gave, never park on a question. Settle every message you act on.
